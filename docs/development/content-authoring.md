# Authoring proficiency content

1. Add the level to `data/<language>/proficiency/framework.json`.
2. Add `<level>.json`: domains, competencies (`skills`, `availability`,
   `examAligned`, localized `title`), thresholds, and assessment sections.
   Every `skills` entry must be a skill the language module declares.
3. Keep a competency `planned` until activities exist for its skills.
4. Write original content only. Cite official sources; never copy exam items or
   textbook text.
5. Run `npm run content:validate` (checks schema, skill ids and locales) and
   `npm test`.

## Practice content: situations, texts and conversations

Practice stages draw on two content folders next to `sentences/`. Both are validated by `npm run content:validate` and seeded with the rest.

- `data/japanese/situations/*.json`: `{ slug, kind: "context" | "free", model, romaji?, prompt: { en, id } }`. `context` situations expect one appropriate reply; `free` ones are written in the learner's own words and the model is only an example.
- `data/japanese/passages/*.json`: `{ slug, form: "text" | "dialogue", lines: [{ speaker?, text }], answer, comprehension: { en: { question, options[4] }, id: { … } } }`. `answer` is the index of the correct option and is the same in every locale; options must differ from each other.

After adding or changing Japanese text, rebuild the audio (`python3 scripts/audio/build-audio.py`). A conversation is one clip: its lines joined with a space.

## Native sentences (Tatoeba)

`data/japanese/native/tatoeba.json` is generated by `python3 scripts/content/import-tatoeba.py` (CC BY 2.0 FR; see the README in that folder). Each item keeps the Tatoeba sentence id and author, plus the id and author of the English and Indonesian translations; the app shows them after an answer. Add ids to `EXCLUDE_IDS` in the script to drop a sentence, then re-run the import and `python3 scripts/audio/build-audio.py`.

## Authentic texts with furigana (Aozora Bunko)

`data/japanese/passages/aozora-excerpts.json` is generated by `python3 scripts/content/import-aozora.py`. Add an excerpt to `EXCERPTS` with the first and last words of the passage; the Japanese is cut from the source (never retyped), including its furigana in Aozora notation: `私《わたし》`, or `丁度｜地獄《じごく》` when the reading covers only part of the kanji run. Forms `paragraph` and `authentic` need a `credit` and a `gloss` (meaning) in every locale; the validator checks both. These texts are public domain; check the author's death date before adding more (Aozora lists it on the card page).

## Levels of Practice content

A passage file has a `level`; an excerpt may override it with its own `level` (used for the Aozora excerpts, set in `LEVEL` in `import-aozora.py`). Practice only offers content up to the learner's current level, so set it to the level needed to read the text with furigana and the meaning.
